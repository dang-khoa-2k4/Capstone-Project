
\section{Convex Analysis and Optimization}

\subsection{Convex Sets}
Before discussing optimization problems, we establish the fundamental geometric
objects used in this work. A set $\mathcal{C} \subseteq \mathbb{R}^n$ is defined
as \textit{convex} if, for any two points within the set, the line segment
connecting them lies entirely within the set.

\begin{figure}[h]
    \centering
    \includegraphics[width=1\textwidth]{theoretical-background/image/convex_sets.png}
    \caption[Convex Sets Examples]{Examples of convex and nonconvex sets. Left: The hexagon (including boundary) is convex. Middle: The kidney-shaped set is nonconvex, as the connecting line segment exits the set. Right: The square with partial boundary inclusion is not convex.\cite{boyd2004}}\label{fig:convex_set}
\end{figure}

Closely related to convexity is the concept of the \textbf{convex hull}. The
convex hull of a set of points $\{x_1, x_2, \dots, x_m\} \subseteq \mathbb{R}^n$
is the smallest convex set containing those points, formally defined as the set
of all convex combinations:

\begin{figure}[h]
    \centering
    \includegraphics[width=0.6\textwidth]{theoretical-background/image/convex_hull.png}
    \caption[Convex Hull Examples]{The convex hull of a set of points (depicted as the shaded area).\cite{boyd2004}}
    \label{fig:convex_hull}
\end{figure}

In the context of motion planning and this thesis, we primarily focus on two
specific types of convex sets:
\begin{itemize}
    \item \textbf{Polyhedra:} Defined as the intersection of a finite number of halfspaces, represented as $\mathcal{P} = \{x \in \mathbb{R}^n \mid Ax \leq b\}$. When a polyhedron is bounded, it is referred to as a \textit{polytope}.
    \item \textbf{Ellipsoids:} Defined as the image of a unit ball under an affine transformation. These are typically represented as $\mathcal{E} = \{x \in \mathbb{R}^n \mid (x-c)^\top Q^{-1} (x-c) \leq 1\}$, where $Q$ is a positive definite matrix ($Q \succ 0$).
\end{itemize}

\subsection{Convex Cones and Homogenization}
A subset $\mathcal{K} \subseteq \mathbb{R}^n$ is a \textit{cone} if it is closed
under positive scalar multiplication (i.e., $\theta x \in \mathcal{K} \forall x
\in \mathcal{K}, \theta \geq 0$). A set is a \textit{convex cone} if it is both
convex and a cone. Two critical concepts regarding convex cones are essential
for this work: perspective cones (constructed via homogenization) and dual
cones.

\subsubsection{Perspective Cones and Homogenization}
Homogenization is a powerful technique in convex analysis used to transform a
general convex set into a cone in a higher-dimensional space. This process
effectively ``lifts'' a set $\mathcal{S} \subseteq \mathbb{R}^n$ into
$\mathbb{R}^{n+1}$ by introducing an auxiliary dimension $y$. The homogenization
$\widetilde{\mathcal{S}}$ is defined as:
\begin{equation}
    \widetilde{\mathcal{S}} := \{(x, y) \in \mathbb{R}^{n+1} \mid y > 0, x \in y\mathcal{S}\}.
    \label{eq:homogenization_def}
\end{equation}
Crucially, $\widetilde{\mathcal{S}}$ is convex if and only if the original set $\mathcal{S}$ is convex. This transformation allows for the representation of convex combinations within a conic structure, which is particularly useful for converting affine constraints into conic forms in optimization.

When a convex set $\mathcal{C}$ is described in a standard conic form, its
homogenization is computationally straightforward. Observing that for $y > 0$,
the set $y\mathcal{C}$ satisfies $\{yx \mid Ax + b \in \mathcal{K}\} = \{x' \mid
Ax' + by \in \mathcal{K}\}$, we derive the \textit{perspective cone}:
\begin{equation}
    \widetilde{\mathcal{C}} = \{(x, y) \in \mathbb{R}^{n+1} \mid y > 0, Ax + by \in \mathcal{K}\}.
    \label{eq:perspective_cone}
\end{equation}
Of significant practical relevance is the closure of this set, $\text{cl}(\widetilde{\mathcal{C}}) = \{(x, y) \mid y \geq 0, Ax + by \in \mathcal{K}\}$. This closure extends the definition to include the boundary where y=0, which is critical for modeling logical constraints in mixed-integer programming.

For a compact set $\mathcal{C}$, as the scalar $y$ approaches zero, the scaled set $y\mathcal{C}$ continuously shrinks towards the origin. Consequently, in the limit where $y=0$, the condition $(x, 0) \in \text{cl}(\widetilde{\mathcal{C}})$ implies that $x$ must be the zero vector (assuming $\mathcal{C}$ contains the origin and is bounded). This geometric behavior effectively functions as a logical switch:
\begin{itemize}
\item When $y > 0$, the variable $x$ is constrained to a scaled version of the set $\mathcal{C}$.
\item When $y = 0$, the variable $x$ is forced to the origin ($x=0$).
\end{itemize}
This property is directly exploited in our application to Shortest Path Problems in Graphs of Convex Sets (GCS). In the Mixed-Integer Convex Programming (MICP) formulation, the binary activation variable for an edge serves as the scaling factor $y$. When an edge is inactive ($y=0$), the associated state contributions are forced to zero, and the cost---modeled via the perspective function---naturally vanishes. The perspective function $\tilde{\ell}_e$ is defined to return $0$ when both $y=0$ and the state variables are $0$, ensuring that inactive components incur no cost in the optimization objective.

\subsubsection{Dual Cones}
The second essential concept is the \textit{dual cone}. For a convex cone
$\mathcal{K} \subseteq \mathbb{R}^n$, the dual cone $\mathcal{K}^*$ consists of all
vectors making a non-negative inner product with every vector in $\mathcal{K}$:
\begin{equation}
    \mathcal{K}^* := \{y \in \mathbb{R}^n \mid x^\top y \geq 0, \forall x \in \mathcal{K}\}.
    \label{eq:dual_cone}
\end{equation}
A fundamental property is that $\mathcal{K}^*$ is always convex, regardless of whether $\mathcal{K}$ is convex. We frequently encounter three specific classes of cones, all of which are \textit{self-dual} (i.e., $\mathcal{K}^* = \mathcal{K}$):
\begin{enumerate}
    \item The \textbf{non-negative orthant}: $\mathbb{R}^n_+ = \{x \in \mathbb{R}^n \mid
          x_i \geq 0\}$.
    \item The \textbf{second-order cone} (Lorentz cone): $\mathcal{Q}^n = \{(t, x) \in
          \mathbb{R} \times \mathbb{R}^{n-1} \mid \|x\|_2 \leq t\}$.
    \item The \textbf{positive semidefinite cone}: $\mathcal{S}^n_+ = \{X \in
          \mathcal{S}^n \mid X \succeq 0\}$.
\end{enumerate}

\subsection{Convex Functions}
A function $f: \mathcal{D} \to \mathbb{R}$ is \textit{convex} if its domain
$\mathcal{D} \subseteq \mathbb{R}^n$ is a convex set and if, for all $x, y \in
\mathcal{D}$ and $\theta \in [0, 1]$, the following inequality holds:
\begin{equation}
    f(\theta x + (1-\theta)y) \leq \theta f(x) + (1-\theta)f(y).
\end{equation}
Geometrically, the line segment connecting any two points on the function's
graph lies above or on the graph. A function is \textit{strictly convex} if
this inequality holds strictly for $x \neq y$ and $\theta \in (0, 1)$. Conversely,
$f$ is \textit{concave} if $-f$ is convex.

The most critical analytical property of convex functions in optimization is
that \textbf{any local minimum is guaranteed to be a global minimum}.

\subsection{Optimization Problems}

\subsubsection{Convex Optimization}
A \textbf{Convex Program (CP)} is formulated as:
\begin{subequations}
    \label{eq:convex_program}
    \begin{align}
        \text{tối thiểu hóa} \quad   & f(x) \label{eq:cp_objective}                \\
        \text{với điều kiện} \quad   & x \in \mathcal{C}, \label{eq:cp_constraint}
    \end{align}
\end{subequations}
where the objective function $f$ and the feasible set $\mathcal{C}$ are both convex. A point $x^{\text{opt}}$ is an \textit{optimal solution} if it is feasible and $f(x^{\text{opt}}) \leq f(x)$ for all $x \in \mathcal{C}$.

While theoretical convexity does not strictly guarantee efficiency (e.g.,
checking non-negativity of polynomials is NP-hard despite the set being a
convex cone), for the purpose of this thesis, we use ``convex optimization
problem'' as a synonym for ``efficiently solvable optimization problem.'' The
majority of practical CPs can be solved reliably using interior-point methods.

\subsubsection{Conic Optimization}
A \textbf{Conic Program (KP)} is a subclass of CP with a linear objective and
constraints defined by a convex cone $\mathcal{K}$:
\begin{subequations}
    \label{eq:conic_program}
    \begin{align}
        \text{minimize} \quad   & c^\top x \label{eq:kp_objective}                 \\
        \text{subject to} \quad & Ax + b \in \mathcal{K}. \label{eq:kp_constraint}
    \end{align}
\end{subequations}
Specific classes of KPs include:
\begin{itemize}
    \item \textbf{Linear Programs (LP):} $\mathcal{K}$ is the non-negative orthant.
    \item \textbf{Second-Order Cone Programs (SOCP):} $\mathcal{K}$ is the product of second-order cones.
    \item \textbf{Semidefinite Programs (SDP):} $\mathcal{K}$ is the semidefinite cone.
\end{itemize}
These classes represent a hierarchy of modeling power: $LP \subset SOCP \subset SDP$. Another common class is the \textbf{Quadratic Program (QP)}, which has a quadratic objective and polyhedral constraints. While every QP can be formulated as an SOCP, specialized active-set algorithms for QPs are often more effective.

\subsubsection{Mixed-Integer Programs}

\textbf{Mixed-Integer Programs (MIPs)} generalize optimization by partitioning variables into continuous vector $x \in \mathbb{R}^n$ and integer vector $z \in \mathbb{Z}^m$:
\begin{subequations}\label{eq:mip}
    \begin{align}
        \text{minimize} \quad   & f(x, z) \label{eq:mip_objective}                  \\
        \text{subject to} \quad & (x, z) \in \mathcal{C}, \label{eq:mip_constraint} \\
                                & z \in \mathbb{Z}^m. \label{eq:mip_integer}
    \end{align}
\end{subequations}
The integrality constraint renders the feasible set non-convex and discrete, typically making MIPs NP-hard. Standard methods relying on differentiability are inapplicable.

To solve MIPs, \textbf{relaxation} is commonly employed (e.g., replacing $z_j
\in \{0,1\}$ with $0 \leq z_j \leq 1$). The optimal value of the relaxed problem
provides a lower bound on the MIP solution. If the relaxed solution is not
integer-feasible, algorithms like \textbf{Branch-and-Bound} are used. This
method systematically partitions the search space into sub-regions (branches)
to eliminate fractional values, exploring a search tree to find the global
optimum.
